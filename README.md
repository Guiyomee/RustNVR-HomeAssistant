# RustNVR · apps Home Assistant

Les apps Home Assistant de [RustNVR](https://github.com/Guiyomee/RustNVR),
l'enregistreur vidéo léger pour caméras RTSP.

| App | Pour qui |
| --- | --- |
| **[RustNVR Proxy](rustnvr-proxy/)** | RustNVR tourne **ailleurs** (Docker, Proxmox, Debian) : l'app affiche son interface dans la barre latérale de Home Assistant. |

L'app « RustNVR », pour faire tourner RustNVR **dans** Home Assistant OS,
arrivera ici avec une prochaine version.

## Installer

Paramètres → **Apps** → **Magasin d'apps** → ⋮ → **Dépôts**, ajoutez :

```
https://github.com/Guiyomee/RustNVR-HomeAssistant
```

puis installez l'app. Guide complet :
[wiki de RustNVR](https://github.com/Guiyomee/RustNVR/wiki/FR-Home-Assistant).

---

*English:* Home Assistant apps for [RustNVR](https://github.com/Guiyomee/RustNVR).
**RustNVR Proxy** shows the interface of a RustNVR running elsewhere in the
Home Assistant sidebar; an app running RustNVR inside Home Assistant OS
comes with a later version. Add this repository in Settings → Apps →
App store → ⋮ → Repositories. Guide:
[wiki](https://github.com/Guiyomee/RustNVR/wiki/EN-Home-Assistant).
