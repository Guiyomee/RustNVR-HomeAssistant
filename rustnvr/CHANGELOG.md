# Journal des versions

La version de l'app suit celle de RustNVR (voir le
[CHANGELOG de RustNVR](https://github.com/Guiyomee/RustNVR/blob/main/CHANGELOG.md)).

## 2026.11.11

- Première version : RustNVR dans Home Assistant (x86-64 et ARM 64 bits),
  interface dans la barre latérale (ingress), enregistrements dans
  `/media/rustnvr`, MQTT branché sur le broker de Home Assistant au premier
  démarrage.
