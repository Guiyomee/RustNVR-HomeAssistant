# RustNVR

[RustNVR](https://github.com/Guiyomee/RustNVR) dans Home Assistant : un
enregistreur vidéo léger pour caméras RTSP (H.264/H.265 enregistrés sans
réencodage), avec son interface dans la barre latérale. Pour un RustNVR qui
tourne déjà sur une autre machine, prenez plutôt l'app « RustNVR Proxy ».
